QQ机器人管理器 1.3.1 宝塔 MySQL 与 EdgeOne 免费版

业务记录使用 MySQL。data/config.json 仅为自动生成的私密配置，并不是数据库。
不要把数据库密码、账号中心 Secret、更新私钥发到聊天。

1. 宝塔安装 PHP 8.2+、MySQL，启用 pdo_mysql、sodium、zip、curl、session。
   网站 PHP 和下面命令使用的 PHP 版本须一致。82 代表 8.2，8.3 改为 83。
2. 宝塔“数据库”创建专用数据库及账号，字符集 utf8mb4，本地访问，不使用 root。
3. 将本 ZIP 内容直接解压到 /www/wwwroot/botmanager.uuze.cn。
   此目录下应直接有 src、public、bin、database 等，不要再多套一层目录。
   网站运行目录设为 /public。Nginx 参考 deploy/nginx.conf，保留已有 HTTPS 证书。
4. 新安装：在宝塔文件管理复制 config.example.php 为 config.php，填写 database 中：
   host=127.0.0.1、port=3306、name=实际库名、username=专用账号、password=实际密码。
   config.php 必须仍为完整的 PHP return 数组。不要只改 config.example.php。
   config.php 所有者 www、权限 600，data 目录给 www 读写，其他代码只需可读。
5. 宝塔终端运行：
   cd /www/wwwroot/botmanager.uuze.cn
   sudo -u www /www/server/php/82/bin/php bin/manage.php install
   sudo -u www /www/server/php/82/bin/php bin/manage.php db-check
   install 自动生成 data/config.json、密钥和五张 MySQL 表，重复执行不重置有效密钥或数据。
   未先复制配置时，install 也会尝试生成 config.php，填好后再运行即可。
6. 在 config.php 填写杂鱼账号 uuze_client_id / uuze_client_secret。
   回调：https://botmanager.uuze.cn/api/admin/oauth/callback
   权限：public_profile user_email。管理员：2377130783@qq.com。
   后台：https://botmanager.uuze.cn/admin

升级旧部署：先备份数据库和 data。仅覆盖代码，保留已有 config.php 和整个 data。
旧 data/config.json 中的数据库和 OAuth 参数仍可用；不要直接用空模板覆盖已有配置。
没有真实 config.php / config.json 被放进本 ZIP，是为了防止覆盖或泄露服务器密钥。
本版增加设备名称、型号、系统版本和架构；覆盖代码后须执行上面的 install 和 db-check。
db-check 应显示“数据表版本 2”。升级只新增缺少的字段，原记录及密钥不变，可重复执行。
1.3.1+12 客户端首次默认统计、启动自动登记；旧版已关闭选择保留，用户仍可关闭并删除。

EdgeOne 免费版获取访问 IP：
1. 先配好 HTTPS 回源，再用“设置/覆盖”添加 X-QQM-Origin-Token 回源头并发布规则。
   值在服务器本机运行 php bin/manage.php origin-token 查看，不要截图或发到聊天。
2. 在服务器已有 config.php 的 return 数组内修改/新增以下字段，保留其他配置：
   'proxy_trust_mode' => 'edgeone_token',
   'require_origin_token' => true,
   'trusted_proxy_cidrs' => [],
   'client_ip_header' => 'EO-Connecting-IP',
   不需要付费版的源站防护网段。默认严格模式仍保留，不会自动放宽已有部署。
3. 后台“部署与安全”点击“立即检测”，成功显示 accepted 和 EO-Connecting-IP。
   免费版 trusted_cidrs_count 为 0 是正常的。设备记录在客户端启动或下一次心跳更新。
密钥模式依赖密钥保密，不替代网络层防火墙。强制鉴权后直接访问源站动态接口应返回 403。
只改 config.example.php 无效。保留 signing_secret，切勿为修复 IP 重生成更新签名密钥。
