1. 解压与启动

当前支持 Ubuntu 22.04 x86_64，不是 ARM 包。从同一版本的 GitHub Release 下载 Linux .tar.gz 和 .sha256 文件，放在同一目录。

sha256sum -c qqbotmanager-linux-v1.3.8-beta.6-build25-web-x64.tar.gz.sha256
tar -xzf qqbotmanager-linux-v1.3.8-beta.6-build25-web-x64.tar.gz
cd qqbotmanager
./start.sh

默认监听 127.0.0.1:23336，仅服务器本机可访问。首次使用必须先设置自己的管理密码，不能跳过。

  1. 在服务器本地执行 cat data/setup-token.txt，复制一次性初始化码；使用 --data 时请查看该私有目录。
  2. 打开网页，在首次设置页粘贴初始化码，设置并确认至少 12 个字符的管理密码。
  3. 之后使用自己设置的密码登录。初始化码完成设置后自动失效并移除，网页不会提供下载。

初始化码用来防止他人抢先设置密码，不是日后的登录密码。不要填写个人 QQ 密码，也不要将初始化码、管理密码或机器人密钥发送到反馈中。未完成设置时，管理接口、机器人自动连接与插件定时任务均不可用。

旧版 Linux 的自动生成密码会作为初始化码迁移到 setup-token.txt，仍需先设置自己的管理密码；不会清空机器人或聊天数据。设置完成后，重启与后续升级会保留管理密码。

2. 从电脑和手机安全访问

推荐：HTTPS 反向代理

使用宝塔或 Nginx 将自己的 HTTPS 域名代理到 http://127.0.0.1:23336。保留 Host 请求头，并在启动参数添加 --public-url https://你的域名。应用会校验请求来源，为登录 Cookie 启用 Secure。

./start.sh --public-url https://bot.example.com

反向代理保留 proxy_set_header Host $http_host;，云防火墙和系统防火墙不必开放 23336。不要把 data 或 /var/lib/qqbotmanager 设为静态网站根目录。

可选：SSH 隧道

ssh -L 23336:127.0.0.1:23336 用户@服务器IP

随后在电脑打开 http://127.0.0.1:23336。

受信局域网临时测试

运行 ./start.sh --host 0.0.0.0，访问 http://服务器局域网IP:23336。HTTP 不加密，不要用于公网。界面会按电脑、手机的屏幕自动适配。

3. 开机运行

将程序文件放到 /opt/qqbotmanager，以专用低权限用户运行。程序包附带 qqbotmanager.service，使用前确认路径与本机环境一致。

useradd --system --home-dir /var/lib/qqbotmanager --shell /usr/sbin/nologin qqbotmanager
cp /opt/qqbotmanager/qqbotmanager.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now qqbotmanager
systemctl status qqbotmanager

已有同名用户时跳过创建命令。数据目录为 /var/lib/qqbotmanager，首次初始化码保存在 /var/lib/qqbotmanager/setup-token.txt，在服务器查看后到网页设置管理密码。已初始化时不再生成该文件。HTTPS 反代时，在 service 的 ExecStart 尾部追加 public-url 参数后重载、重启服务。关闭浏览器不会停止机器人。

4. 更新与备份

Linux 版是独立服务包，目前不参与 Windows 等四端客户端的自动替换流程。下载新版本，停止服务，备份私有数据目录，替换程序及随附资源，保留原有数据，再启动服务。不要将新的空数据目录覆盖旧记录。

聊天、机器人配置、自定义插件和插件数据保存在服务器；不会自动与手机或桌面客户端同步。私有目录含凭据，请限制访问并妥善备份。

5. 网页工作台

  • 通过 AppID 和机器人密钥接入，支持多机器人切换与聊天隔离。
  • 文字、Markdown 编辑与实时预览、HTTPS 图片链接发送；新消息不抢阅读位置，发送成功后定位最新。
  • 设置左侧的铃铛进入独立群通知中心，可筛选加入／退出、未读、待审核和已处理申请，分页同步并手动同意或拒绝；拒绝不默认拉黑。
  • 会话内齿轮打开群聊／用户设置。可查看群人数、简介、机器人身份和接收模式、分页成员和详细资料、禁言规则；有权限时可审批、禁言／解除禁言以及撤回普通成员 2 分钟内的消息。
  • 长按／右击会话或进入会话设置可屏蔽消息提醒，保留聊天记录，不影响机器人和插件收发。
  • 七个随附插件与第三方使用同一加载器，可导入 JSON/YAML/脚本定义、编辑工作区文件、保存并安装；默认关闭。
  • 日志按状态着色，支持全部复制和导出 TXT/LOG；支持浅色、深色及跟随系统。
  • IPv4 诊断显示的是服务器的公网出口，不是浏览网页的手机或电脑。
  • 群聊使用本地群组图标，单聊用户与群成员的个人头像正常展示。网页内嵌链接保留访问设备的浏览器标识；第三方网站禁止嵌入时可复制链接。

默认展示会话最近 500 条消息，更早记录仍保留在服务器本地。部分群管理能力需要平台内邀／白名单，入群审核与禁言还需要机器人为群管理员。网页不申请浏览器系统通知权限，系统通知仅 Android／iOS 客户端提供，且不保证 App 被系统挂起或关闭后的离线推送。
