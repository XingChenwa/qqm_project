LINUX / WEB CONSOLE

安装简单，入口专属。

服务器后台运行，用电脑或手机浏览器管理。第一次打开网页，再设置管理员密码和你的安全入口。

版本说明：本文适用于 1.3.9 及以上。1.3.8 系列旧包不包含自动安装器与安全入口，安装器会拒绝不支持的旧包。请等对应 Release 的 Linux 附件上传齐备后安装。

1. 不只支持 Ubuntu

  • Linux x86_64 / amd64，glibc 2.31 或以上。适用于满足要求的 Ubuntu、Debian、Rocky Linux / AlmaLinux、Fedora、Arch 等，不按发行版名称限制安装。
  • 自动安装需要正在运行的 systemd；其他 init 系统可使用服务包中的 start.sh 手动运行。
  • 目前不是 ARM / aarch64 包，也不适用于 Alpine / musl。安装器会检查，不会替换系统运行库。
  • 无需桌面、Flutter、Dart、PHP 或数据库。服务器需能访问 QQ 开放平台，源 IP 白名单填写服务器公网 IPv4。

发布流程会在 Ubuntu 22.04、Debian 12、Rocky Linux 9 容器中检查服务启动，实际兼容以相应 Release 的验证结果为准。

2. 自动下载、校验、安装

下载安装器，查看来源与内容后执行。默认选择正式版 --channel stable：

curl -fL --proto '=https' --proto-redir '=https' \
  https://raw.githubusercontent.com/XingChenwa/qqm_project/main/server/install.sh \
  -o qqm-install.sh
sudo bash qqm-install.sh --channel stable --install-deps

没有 curl 时，Ubuntu / Debian 先安装 curl ca-certificates；Rocky / AlmaLinux / Fedora 使用 dnf 安装。--install-deps 支持 apt、dnf、yum、zypper、pacman，不修改防火墙或 SSH。只检查环境可用 bash qqm-install.sh --check-only。

SHA-256 是什么？不需要手动算。

它是文件的“指纹”，用于发现安装包损坏或被修改。安装器自动下载校验值、验证后才解压，还会拒绝越界路径、链接和特殊文件。请只从可信 HTTPS 来源下载；单独一个校验值不代表来源可信。

安装后服务自动后台运行：程序 /opt/qqbotmanager，私有数据 /var/lib/qqbotmanager，默认端口 23336。密码不在安装终端设置，下一步在浏览器完成。

3. 第一次打开，设置密码和安全入口

打开 http://服务器局域网IP:23336 会显示首次设置页。安装终端还会提供私有链接，自动填入一次性初始化码：

http://服务器IP:23336/#setup=一次性初始化码

不要分享这条私有链接。它用于证明你拥有服务器，防止陌生人从公网抢先设置管理员；初始化码不是管理密码。网页会清除地址片段，片段不进入服务端 URL 或访问日志；HTTP 提交仍不加密，请优先使用 HTTPS。

  1. 在网页设置至少 12 个字符的管理员密码，并再次确认。
  2. 填写 8–64 位字母、数字、短横线或下划线的安全入口，也可以点击“随机生成”，不要使用容易猜的 xxxx。
  3. 保存后进入类似 http://服务器IP:23336/mybot_7rK92p/ 的地址，收藏完整入口。

完成前，不能使用管理接口、连接机器人或运行插件定时任务。完成后，根地址和错误入口返回 404，不会跳转或泄露正确入口；正确入口仍需密码登录。设置保留到重启和升级，只保存加盐密码哈希，初始化码自动失效并删除。

没有使用私有链接时，可在服务器查看初始化码并在页面粘贴：

sudo cat /var/lib/qqbotmanager/setup-token.txt

已设置密码的旧版安装升级后，使用原密码登录，再补设入口，机器人和聊天保留。不要删除密码文件或清空数据目录。

4. 局域网能访问，公网也能配置

自动安装默认监听 0.0.0.0:23336。局域网地址只在对应网络可用；公网须使用公网 IP / 域名，并放行云安全组与系统防火墙的 TCP 23336：

http://服务器局域网IP:23336/你的安全入口/
http://服务器公网IP:23336/你的安全入口/
https://你的域名/你的安全入口/

家用网络通常还需路由器端口映射和可入站公网地址；运营商 CGNAT 下仅开放端口不一定能访问。安装器不自动修改防火墙。请按自己的系统与安全要求放行，尽量限制来源 IP，不要关闭整个防火墙。

HTTP 不加密密码、Cookie 或聊天，安全入口也不能加密。 公网长期使用推荐 HTTPS 或 VPN。仅本机访问可在安装时加 --host 127.0.0.1，远程电脑通过 SSH 隧道访问：

ssh -L 23336:127.0.0.1:23336 用户@服务器IP

随后访问本机 23336。手机和电脑浏览器自动显示对应布局。

5. HTTPS 反向代理（推荐）

  1. 配置指向服务器的域名及有效 HTTPS 证书。
  2. 编辑 /etc/qqbotmanager.env，填写下面的设置，不在域名后加安全入口。
  3. 反向代理整个网站到本机 23336，保留原始 Host 和完整入口路径，重启服务。
  4. 使用 HTTPS 域名及完整入口。此模式校验域名与 Origin，并启用 Secure 登录 Cookie。
QQM_HOST=127.0.0.1
QQM_PORT=23336
QQM_PUBLIC_URL=https://你的域名
location / {
    proxy_pass http://127.0.0.1:23336;
    proxy_set_header Host $http_host;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 1m;
    proxy_read_timeout 90s;
}

仅公开 HTTPS 所需端口，无需把 23336 暴露公网。不要将私有数据目录设成网站根目录，不缓存管理页面和 API。

6. 后台服务与找回入口

sudo systemctl status qqbotmanager --no-pager
sudo systemctl restart qqbotmanager
sudo systemctl stop qqbotmanager
sudo journalctl -u qqbotmanager -n 100 --no-pager
# 仅在服务器终端显示私有入口，不重置任何设置：
sudo bash /opt/qqbotmanager/install.sh --print-link
# 需要显示实际公网访问地址时：
sudo bash /opt/qqbotmanager/install.sh --print-link --access-url http://公网IP:23336

首次使用显示一次性设置链接，已设置后显示安全入口。正常服务日志不输出这些私有链接。分享日志、截图前去除初始化码、入口、密码、密钥与 Token。

7. 更新、备份与离线安装

更新时重复运行安装器，同一渠道安装最新可用包；也可用 --version v版本号 指定 Release。--channel stable 与 --channel beta 分开，不会自动跨渠道：

sudo bash qqm-install.sh --channel stable
# 离线：先上传 tar.gz 和同名 .sha256，再自动校验安装：
sudo bash qqm-install.sh --archive /下载目录/完整Linux安装包文件名.tar.gz

升级会保留密码、入口、聊天与插件数据。私有数据和旧程序备份在 /var/backups/qqbotmanager/时间编号，启动检查失败恢复旧程序，不重置数据。备份包含凭据，请勿公开。不是由安装器管理的旧安装目录会被拒绝覆盖，需先备份并按完整文档迁移。

已解压可信新包可运行 sudo bash install.sh --local。没有 systemd 的系统可在包目录手动执行 ./start.sh --host 0.0.0.0 --port 23336，另一个终端执行 ./qqm-server --data ./data --access-link http://服务器IP:23336 获取私有链接；自己配置守护程序。程序目录的 data 与系统服务数据不会自动混合。

常见问题

  • 根地址 404：初始化后正常，请用完整安全入口；忘记入口用服务器上的 --print-link，不要重新初始化。
  • 网页不通：先检查服务，再用 curl -f http://127.0.0.1:23336/health；HTTPS 模式加正确 Host。外网不通时检查监听、安全组、防火墙和端口映射。
  • 公网 IP 显示错：安装器看到的本机 IP 不一定是路由器出口，可在显示链接时指定 --access-url。
  • 初始化码不见了：设置成功会删除，未初始化先核对实际数据目录。
  • SHA-256 不符：重新从可信 Release 下载，不跳过校验，不用源码 ZIP。
  • 端口占用：安装加 --port 23337 或改环境文件后重启，并同步修改访问地址和网络规则。
  • QQ 源 IP 白名单：使用服务器出口 IPv4，不是浏览者 IP。

网页工作台支持什么

  • 多机器人切换和聊天隔离；文字、Markdown、图片链接与按钮消息。
  • 群通知、入群审核、成员资料与禁言状态；长按成员头像可禁言、解除禁言或移出，移出二次确认、不默认拉黑。
  • 会话免打扰；收到新消息不抢阅读位置，主动发送后定位最新。
  • 七个随附插件与第三方共用加载器，支持源码编辑和导入，默认关闭。
  • 电脑与手机布局、浅色 / 深色主题、按状态着色的日志与复制导出。

群管理能力受 QQ 平台白名单和管理员身份约束。网页不申请系统通知权限；移动客户端也不保证 App 挂起后的离线推送。Linux 服务暂不参加四端客户端的自动替换更新流程。
