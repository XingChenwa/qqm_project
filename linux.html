UBUNTU 22.04 / WEB CONSOLE

Linux 安装与使用。

从下载、首次设置密码到后台运行，一步步部署 QQ机器人管理器。无需桌面环境，用电脑或手机浏览器访问。

1. 安装前确认

  • 系统为 Ubuntu 22.04，x86_64 / amd64。执行 uname -m 应显示 x86_64，当前安装包不适用于 ARM / aarch64。
  • 不需要图形桌面、Flutter、Dart、PHP 或数据库，安装包包含可执行程序。
  • 服务器需要能访问 QQ 开放平台。机器人源 IP 白名单填写服务器的公网 IPv4，不是电脑或手机的 IP。
  • 默认端口 23336，仅监听本机；不会自动向公网开放。

先安装下载与解压工具：

sudo apt update
sudo apt install -y ca-certificates curl tar libstdc++6 libgcc-s1

2. 下载并启动（普通用户）

从 GitHub Releases 下载同一版本的 Linux .tar.gz 和同名 .sha256，不要下载源码 ZIP。下面以 1.3.8-beta.7.2+28 为例；该版本附件上传后即可执行。已有安装请看“更新与备份”，不要重新初始化数据。

mkdir -p "$HOME/qqm-downloads"
cd "$HOME/qqm-downloads"
curl -fL --retry 3 -O https://github.com/XingChenwa/qqm_project/releases/download/v1.3.8-beta.7.2/qqbotmanager-linux-v1.3.8-beta.7.2-build28-web-x64.tar.gz
curl -fL --retry 3 -O https://github.com/XingChenwa/qqm_project/releases/download/v1.3.8-beta.7.2/qqbotmanager-linux-v1.3.8-beta.7.2-build28-web-x64.tar.gz.sha256
sha256sum -c qqbotmanager-linux-v1.3.8-beta.7.2-build28-web-x64.tar.gz.sha256
# 只有出现 OK / 成功，才继续解压。
tar -xzf qqbotmanager-linux-v1.3.8-beta.7.2-build28-web-x64.tar.gz
cd qqbotmanager
./start.sh

保持这个终端运行，停止时按 Ctrl+C。关闭 SSH 后仍要运行，请使用后面的 systemd 服务。

3. 用浏览器打开网页

服务器本机浏览器打开 http://127.0.0.1:23336。默认只监听本机，直接访问公网 IP 的 23336 端口不会通，这是正常的安全设置。

远程电脑：SSH 隧道

在你的电脑终端执行下面的命令，不是在服务器终端：

ssh -L 23336:127.0.0.1:23336 你的服务器用户@服务器IP

保持隧道打开，在电脑浏览器访问 http://127.0.0.1:23336。

手机或多人访问

推荐配置后面的 HTTPS 反向代理，然后用手机浏览器打开你的 HTTPS 域名，页面自动适配手机布局。受信局域网临时测试可用 ./start.sh --host 0.0.0.0，再访问 http://服务器局域网IP:23336。HTTP 不加密，不要直接用于公网。

4. 首次设置自己的管理密码

第一次安装必须先设置管理密码，不能跳过。 普通用户模式启动后，在服务器另开一个终端查看初始化码：

cd "$HOME/qqm-downloads/qqbotmanager"
cat data/setup-token.txt
  1. 在网页首次设置页粘贴初始化码。
  2. 输入并确认至少 12 个字符的管理密码，完成后进入工作台。
  3. 以后使用自己设置的密码登录；初始化码完成设置后失效并移除。

初始化码只用来防止别人抢先设置密码，不是日后的登录密码。不要填写个人 QQ 密码，也不要将初始化码、管理密码或机器人密钥发送到反馈中。密码未设置前，所有管理接口、机器人自动连接与插件定时任务均不可用。

使用 --data 时，请在该私有数据目录寻找初始化码。已初始化的服务重启和升级后保留原密码。旧版随机密码会迁移为初始化码，仍需设置自己的密码，不会清空机器人或聊天数据。

5. 后台运行与开机启动

下面按新安装举例，先用 Ctrl+C 停止普通用户模式，在解压后的 qqbotmanager 目录执行：

sudo mkdir -p /opt/qqbotmanager
sudo cp -a qqm-server start.sh qqbotmanager.service server assets plugins LICENSE README.md /opt/qqbotmanager/
id qqbotmanager >/dev/null 2>&1 || sudo useradd --system --user-group --home-dir /var/lib/qqbotmanager --shell /usr/sbin/nologin qqbotmanager
sudo install -m 644 /opt/qqbotmanager/qqbotmanager.service /etc/systemd/system/qqbotmanager.service
sudo systemctl daemon-reload
sudo systemctl enable --now qqbotmanager
sudo systemctl status qqbotmanager --no-pager
sudo cat /var/lib/qqbotmanager/setup-token.txt

使用最后一条命令显示的初始化码，到网页设置密码；已经初始化的服务不会再生成该文件。systemd 以专用低权限用户运行，关闭网页或 SSH 不会停止机器人。

注意：systemd 的数据目录是 /var/lib/qqbotmanager，普通用户模式默认是程序目录下的 data。 切换运行方式不会自动迁移数据。已有机器人和聊天时，请先停止服务、备份，再完整迁移数据并交给服务用户读写，不要把两个目录混合。

sudo systemctl restart qqbotmanager
sudo systemctl stop qqbotmanager
sudo journalctl -u qqbotmanager -n 100 --no-pager

6. 宝塔 / Nginx 配置 HTTPS

  1. 创建自己的 HTTPS 站点，反向代理到 http://127.0.0.1:23336。
  2. 保留原始 Host 请求头：proxy_set_header Host $http_host;。
  3. 普通用户启动时添加 --public-url https://你的域名；systemd 模式在 service 的 ExecStart 尾部追加该参数后重载和重启。
  4. 手机和电脑打开 HTTPS 域名，应用会校验请求来源，并为登录 Cookie 启用 Secure。
./start.sh --public-url https://bot.example.com

云防火墙和系统防火墙只需开放 HTTPS / SSH 所需端口，不必对公网开放 23336。不要把 data 或 /var/lib/qqbotmanager 设为静态网站根目录。

7. 更新与备份

  1. 下载新版 Linux 服务包与校验文件，先验证校验值。
  2. 停止正在运行的程序或执行 sudo systemctl stop qqbotmanager。
  3. 备份原私有数据目录：普通用户为程序目录下的 data，systemd 为 /var/lib/qqbotmanager。
  4. 替换程序、网页和随附资源，保留原有数据，不要用空 data 覆盖旧记录。
  5. 启动原来的运行方式，确认机器人、聊天、插件与管理密码仍在。

Linux 服务包目前不参加四端客户端的自动替换流程，需要手动更新。聊天和插件保存在服务器本地，不会自动与手机、桌面客户端同步；私有数据包含凭据，请妥善备份。

常见问题

  • 下载 404：确认安装包已上传，版本、构建号和文件名与 Release 附件一致。
  • Permission denied：进入程序目录执行 chmod +x qqm-server start.sh；不要使用 chmod -R 777。
  • Exec format error：通常是 CPU 架构不匹配，本包只适用于 x86_64。
  • 网页打不开：先在服务器执行 curl -f http://127.0.0.1:23336/health 确认程序在运行，远程再用 SSH 隧道或 HTTPS 域名。
  • 端口已占用：确认是否已运行一个服务；临时可用 ./start.sh --port 23337，隧道与反向代理端口也要同步修改。
  • 初始化码找不到：确认当前运行方式和数据目录；已设置密码后该文件会被移除，这是正常现象。
  • QQ 提示 IP 不在白名单：把服务器实际公网 IPv4 加到对应 AppID 的 QQ 机器人开发设置。

网页工作台支持什么

  • 多机器人切换、聊天隔离，文字、Markdown、图片链接与按钮消息。
  • 群通知中心、入群审核、群人数、成员资料与禁言状态；长按成员头像可禁言、解除禁言或移出群聊，移出需二次确认且不拉黑。
  • 长按会话可屏蔽提醒，保留消息与插件收发；收到新消息不抢阅读位置，主动发送后定位最新。
  • 七个随附插件与第三方共用加载器，可导入、编辑源码、保存并安装，插件默认关闭。
  • 电脑与手机布局、浅色 / 深色主题、日志按状态着色，支持复制和导出。

部分群管理能力需要 QQ 平台内邀 / 白名单，机器人还需要相应群管理员身份。网页不申请系统通知权限；Android / iOS 系统通知也不保证 App 被挂起或关闭后的离线推送。
