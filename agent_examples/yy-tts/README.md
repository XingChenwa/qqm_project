# 在线角色语音 Skill

默认使用 <https://yy.jujiang.js.cn/tts> 直连接口，发送 `character`（音色）、`text`（朗读正文）、`speed`（语速）三个参数。网站首页是网页界面；这个 Skill 直接取音频，不需要先读取网页配置或提交 Gradio 排队任务。

1. 在新版 QQ机器人管理器的 **QQ Agent → Skills** 导入 `skills-yy-tts-v1.0.2.zip`。现有导入器不覆盖同 ID 包：已有旧版时，先导出备份、记下设置，再删除旧 Skill 后导入新版。
2. 点“插件设置”，选择角色音色和语速。新导入默认 **甜妹**、语速 **1**；如原来用了其他音色，请重新选择。展开高级设置，确认“接口模式”为 **直连 /tts**。
3. 启用这个 Skill，并在当前机器人使用的 **AI 预设**中选中它；模型须支持工具调用，连接须开启自动 AI 回复。
4. 群里按现有唤醒规则 @机器人说“读一下：你好，今天也要开心”；单聊可直接要求朗读。

服务地址可以填 `https://yy.jujiang.js.cn` 或 `https://yy.jujiang.js.cn/tts`。不需要填写带 `text` 参数的整条链接，也不要把 `${encodeURIComponent(aiResponse)}` 原样填进去：这是 JavaScript 变量表达式，插件会自动取实际正文并编码中文、空格、换行、`&`、`+` 和表情。

角色下拉框支持搜索；“自定义角色名称”可填写新增的角色。直连模式的音色查询工具使用随包提供的参考名单，不依赖旧站点配置接口。情感和语言仅在高级设置切换为 **Gradio 排队接口（兼容）** 后生效，不向直连接口发送未经确认的参数。

工具为 `yy-tts__read_aloud`、`yy-tts__list_voices`、`yy-tts__list_emotions`。直连模式执行情感查询时会说明参数范围。朗读正文仅含实际要读的文字，不包含工具计划或思考；音色、语速由插件设置决定。

每次朗读只请求一次合成，不在超时后自动重试或切换接口重复合成。支持直接音频、JSON 音频地址及 HTTPS 下载重定向；HTML、错误响应、过大文件及未取得语音发送回执都会如实报错。外部服务或本机网络异常时仍可能超时，请在 QQ Agent 的运行日志查看原因。文本最多 1000 字，编码后的请求地址不得超过 7500 字符，音频最多 5 MB。QQBot 还受官方格式、被动回复时限和权限限制。

无需另外安装 Node、Python 或 GPU 环境。源码在 `agent_examples/yy-tts/`，可修改后重新打包导入。Skill 代码按本项目 GPL-2.0 许可分发；站点及音色资源的使用条款和署名要求以站点为准。
