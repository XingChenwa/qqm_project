# 在线角色语音 Skill

默认把 <https://yy.jujiang.js.cn/tts> 链接交给机器人适配器 / 平台获取音频，参数为 `character`（音色）、`text`（朗读正文）、`speed`（语速）。这与 `segment.record(ttsUrl)` 的发送方式相同：OneBot 发送 `record` URL，官方 QQBot 通过文件接口的 `url` 参数让 QQ 平台拉取音频，然后发送富媒体消息。管理器不预先下载这段音频，不读取网页配置或提交 Gradio 排队任务。

1. 先安装本次提供的 **URL 语音修复版客户端**（宿主接口版本 4），在 **QQ Agent → Skills** 导入 `skills-yy-tts-v1.0.3.zip`。原先发布的 1.4.1 Beta 1 客户端尚不含 URL 语音接口。现有导入器不覆盖同 ID 包：已有旧版时，先导出备份、记下设置，再删除旧 Skill 后导入新版。
2. 点“插件设置”，选择角色音色和语速。默认 **甜妹**、语速 **1**，发送方式选 **适配器 / 平台获取音频**。如原来用了其他音色，请重新选择。展开高级设置，确认“接口模式”为 **直连 /tts**。
3. 启用这个 Skill，并在当前机器人使用的 **AI 预设**中选中它；模型须支持工具调用，连接须开启自动 AI 回复。
4. 群里按现有唤醒规则 @机器人说“读一下：你好，今天也要开心”；单聊可直接要求朗读。

服务地址可以填 `https://yy.jujiang.js.cn` 或 `https://yy.jujiang.js.cn/tts`。不需要填写带 `text` 参数的整条链接，也不要把 `${encodeURIComponent(aiResponse)}` 原样填进去：这是 JavaScript 变量表达式，插件会自动取实际正文并编码中文、空格、换行、`&`、`+` 和表情。

角色下拉框支持搜索；“自定义角色名称”可填写新增的角色。直连模式的音色查询工具使用随包提供的参考名单，不依赖旧站点配置接口。情感和语言仅在高级设置切换为 **Gradio 排队接口（兼容）** 后生效，不向直连接口发送未经确认的参数。

工具为 `yy-tts__read_aloud`、`yy-tts__list_voices`、`yy-tts__list_emotions`。直连模式执行情感查询时会说明参数范围。朗读正文仅含实际要读的文字，不包含工具计划或思考；音色、语速由插件设置决定。

每次朗读只提交一次，不在失败后自动重复合成。URL 方式仍会校验公共 HTTPS 地址及当前会话，等待真实平台消息 ID；格式、大小、服务连通性由适配器 / 平台处理。适配器不支持 URL 或服务拒绝时会如实报错，不代表已发送。QQBot 还受官方格式、被动回复时限和权限限制。

如确实需要管理器本机下载，可在插件设置切换发送方式；此方式兼容原先发布的客户端，支持直接音频、JSON 地址及 HTTPS 下载重定向，并验证实际音频字节。文本最多 1000 字，编码后的地址最多 7500 字符；本机下载的音频最多 5 MB。旧客户端的 URL 方式会提示升级，不会偷偷切换发送方式。

无需另外安装 Node、Python 或 GPU 环境。源码在 `agent_examples/yy-tts/`，可修改后重新打包导入。Skill 代码按本项目 GPL-2.0 许可分发；站点及音色资源的使用条款和署名要求以站点为准。
