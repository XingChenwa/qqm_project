# 在线角色语音 Skill

支持两种发送方式，参数均为 `character`（音色）、`text`（朗读正文）、`speed`（语速）：

- **URL 优先、自动兼容**：客户端有 URL 接口时，把 <https://yy.jujiang.js.cn/tts> 链接交给适配器 / 平台获取音频，与 `segment.record(ttsUrl)` 相同；旧客户端没有该接口时，在同一次工具调用内自动改为本机下载，再按本地音频上传。
- **始终本机下载**：管理器访问 TTS 接口，验证实际音频后上传发送，适用于支持本地语音数据的旧版客户端。

URL 方式下 OneBot 发送 `record` URL，QQBot 用文件接口的 `url` 参数让平台拉取后发送。真正的 URL 转发仍需要宿主接口版本4；Skill 不会凭提示词给旧客户端创造接口。本机方式仍需能连接 TTS 服务，不是离线合成。两种方式都不读取网页配置或提交 Gradio 排队任务。

1. 在 **QQ Agent → Skills** 导入 `skills-yy-tts-v1.0.4.zip`。已有旧版时，先导出备份、记下设置，再删除旧 Skill 后导入新版；现有导入器不覆盖同 ID 包。
2. 点“插件设置”，选择角色音色和语速。默认 **甜妹**、语速 **1**，发送方式选 **URL 优先，旧客户端自动用本机**；也可以手动选择 **管理器本机下载后发送**。展开高级设置，接口模式选 **直连 /tts**。
3. 启用这个 Skill，并在当前机器人使用的 **AI 预设**中选中它；模型须支持工具调用，连接须开启自动 AI 回复。
4. 群里按现有唤醒规则 @机器人说“读一下：你好，今天也要开心”；单聊可直接要求朗读。

服务地址可以填 `https://yy.jujiang.js.cn` 或 `https://yy.jujiang.js.cn/tts`。不需要填写带 `text` 参数的整条链接，也不要把 `${encodeURIComponent(aiResponse)}` 原样填进去：这是 JavaScript 变量表达式，插件会自动取实际正文并编码中文、空格、换行、`&`、`+` 和表情。

角色下拉框支持搜索；“自定义角色名称”可填写新增的角色。直连模式的音色查询工具使用随包提供的参考名单，不依赖旧站点配置接口。情感和语言仅在高级设置切换为 **Gradio 排队接口（兼容）** 后生效，不向直连接口发送未经确认的参数。

工具为 `yy-tts__read_aloud`、`yy-tts__list_voices`、`yy-tts__list_emotions`。直连模式执行情感查询时会说明参数范围。朗读正文仅含实际要读的文字，不包含工具计划或思考；音色、语速由插件设置决定。

每次朗读只提交一次。自动兼容在提交前判断是否有 URL 接口；如果已经向协议端发送请求，却因网络或回执不明而失败，不再自动换一种方式补发。URL 方式校验公共 HTTPS 地址和当前会话，等待真实消息 ID；格式、大小、服务连通性由协议端处理。最终服务、网络或发送失败时如实返回本次实际原因，不把它统称为“只能等升级”。QQBot 仍受官方格式、被动回复时限和权限限制。

本机下载支持直接音频、JSON 地址及 HTTPS 下载重定向，并验证实际音频字节。文本最多 1000 字，编码后的地址最多 7500 字符；本机下载的音频最多 5 MB。自动转为本机时会在运行日志记录方式，成功仍以消息回执为准。

无需另外安装 Node、Python 或 GPU 环境。源码在 `agent_examples/yy-tts/`，可修改后重新打包导入。Skill 代码按本项目 GPL-2.0 许可分发；站点及音色资源的使用条款和署名要求以站点为准。
