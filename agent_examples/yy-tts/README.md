# 在线角色语音 Skill

对接 <https://yy.jujiang.js.cn/> 的 Gradio `get_audio` 接口，按服务公布的 17 个参数调用。使用现有 QQ Agent 的公共 HTTPS、文件和语音发送接口，无需 Node/npm、Python 或本地 GPU。

1. QQ Agent → Skills → 导入 `skills-yy-tts-v1.0.1.zip`。
2. 点“插件设置”，选择角色音色，修改情感、语速后保存并启用。情感默认 `default`；不同角色可能有不同的可选情感，可先在聊天中查询。
3. 在当前机器人使用的 AI 预设中选中这个 Skill，确认 AI 模型支持工具调用，开启该连接的 AI 回复。
4. 群聊按原唤醒规则 @ 机器人说“读一下：你好，今天也要开心”；单聊可直接要求朗读。

工具：`yy-tts__read_aloud`、`yy-tts__list_voices`、`yy-tts__list_emotions`。两个列表工具只查询资料，不合成语音。模型不能在工具参数里悄悄替换设置中的音色。

优先查询服务当前音色名单；站点配置接口暂不可达时，仅为默认站点使用 2026-10-25 保存的 Gradio 4.37.2 协议与音色快照，并在日志和音色查询结果中标明。如果站点升级了接口，需要更新 Skill。新增角色可在高级设置填写“自定义角色名称”。Gradio 4 使用站点声明的 SSE 排队协议；不重复提交合成，只对查询和已生成音频的下载做有限重试。服务可能排队、停机或调整接口；错误会如实返回，不把失败当成已发送。朗读上限 1000 字，音频 5 MB。QQBot 还受官方格式、被动回复时限和权限限制。

这个包是 TTS 语音朗读，不是 `sing-cover` 的 RVC 翻唱。导入前可关闭暂不使用的其他语音 Skill，避免模型同时选择多个合成工具。
