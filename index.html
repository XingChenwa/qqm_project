清楚地聊，安心地看

单聊与群聊统一管理，支持引用、图片预览和 QQ 表情。收到消息不打断阅读，主动发送后定位到最新。

M↓

Markdown，单独认真写

独立编辑、预览和发送区，搭配消息配置与按钮。桌面端 Enter 发送，Ctrl + Enter 换行。

{ }

插件，不只是一个开关

文件管理、源码编辑、校验、规则试运行与可恢复历史。简单规则本地运行，复杂逻辑交给 HTTP 服务。

↗

工具，也照顾日常细节

应用内浏览网页，日志一键复制或导出。桌面自定义窗口与可选托盘，更新弹窗展示说明和安装进度。

从这里出发

接入，然后开始创造。

  1. 1

    准备官方机器人

    在 QQ 开放平台创建机器人，确认所需权限与接入环境。

  2. 2

    下载并连接

    安装对应客户端，在设置中填写自己的应用凭据并连接。

  3. 3

    挑选你的玩法

    在插件中心配置、启用插件，或者导入你自己写的清单。

写给开发者

从规则，到你自己的服务。

JSON / YAML 写轻量命令，Node.js / Python 等通过 HTTP 接入复杂玩法。
命令、权限、冷却与回复上下文由宿主管理，不直接运行 Yunzai JS 插件。
