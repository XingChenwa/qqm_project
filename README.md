# QQ机器人管理器

基于 QQ 官方开放平台的跨平台中文机器人管理客户端，支持 Windows、macOS、Android 和 iOS。

用一个应用管理机器人会话，收发文字、Markdown 和媒体消息，预览引用与图片，使用天气、翻译、签到、投票等插件，也可以编写自己的规则与玩法。

- 中文会话界面与独立 Markdown 工作区。
- 插件文件管理、源码编辑、校验和试运行。
- 应用内浏览器、日志复制导出、桌面窗口与可选托盘。
- 应用内查看新版说明、下载和安装入口。
